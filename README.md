# bjj-gi-fabric-calculato
A modern web-based calculator that estimates fabric requirements for BJJ Gis using Sialkot factory standards, including waste calculations, roll width conversion, and GSM validation.
BJJ Gi Fabric Calculator

A responsive web application designed to calculate fabric requirements for Brazilian Jiu-Jitsu (BJJ) Gi production based on industry standards commonly used in Sialkot manufacturing facilities.

The calculator helps manufacturers, production managers, and merchandisers estimate:

Total fabric requirements
Base fabric consumption
Fabric waste allowance (8%)
Required linear meters from fabric rolls
GSM category validation (Lightweight / Heavyweight)
Features

✅ Real-time fabric requirement calculations

✅ GSM validation based on weight category

✅ Waste factor integration (8%)

✅ Roll width conversion (59" / 1.5m standard)

✅ Modern glassmorphism UI

✅ Responsive design for desktop and mobile

Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
Industry Standards Used
Fabric per Gi: 3.2 m²
Roll Width: 59 inches (1.4986 m)
Waste Percentage: 8%
Lightweight Gi: ≤ 450 GSM
Heavyweight Gi: ≥ 550 GSM
